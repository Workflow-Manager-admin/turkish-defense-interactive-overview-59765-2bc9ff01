# Türkiye Military Force Interactive Slide Deck

This project is an interactive, media-rich presentation on the Turkish Armed Forces built using [Slidev](https://sli.dev).

## Key Features

- **Modern, Responsive Design:** Clean, branded visuals and color palette matching TAF identity.
- **Sidebar Navigation:** Quick jump to any section or topic.
- **Presenter Mode:** Press `P` to show speaker notes, advanced tools, and audience display.
- **Interactive Slides:** Clickable highlights, image zoom, custom gallery, code, diagrams, and embedded YouTube.
- **Rich Media:** Images and embedded video for full immersion.
- **Custom Theming:** Uses a custom accent color palette (`primary: #0057b8`, `secondary: #e30a17`, `accent: #f9cf02`).

## Getting Started

1. Install dependencies:

   ```
   pnpm install
   ```

2. Start development server:

   ```
   pnpm dev
   ```

   Visit <http://localhost:3030> or the provided local URL.

## How to Use

- Edit `slides.md` to modify slides or add your own.
- For custom layouts and elements, use Vue and Markdown together.
- To switch to Presenter Mode, press `P`.
